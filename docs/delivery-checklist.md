# Delivery Checklist

This checklist records the supplied delivery workflow. Items remain unchecked until their outcomes have been verified. Repository privacy, Netlify configuration, and client approval have not been verified.

- [ ] Create or open the client's private GitHub repository
- [ ] Select the correct repository and environment in Codex
- [ ] Provide the client-specific brief and approved design references
- [ ] Ask Codex to build, test, commit and push a development branch
- [ ] Open or review the GitHub pull request
- [ ] Check the Netlify Deploy Preview
- [ ] Review desktop, tablet, mobile and functional behaviour
- [ ] Send the protected demonstration link to the prospect
- [ ] Finalise client approval, security, compliance and integrations
- [ ] Merge to the configured production branch only when ready
- [ ] Confirm Netlify production deployment and HTTPS
- [ ] Set up the ongoing maintenance and growth package

This checklist does not authorise deployment, production merges, spending, sensitive-data integrations, or sending messages to prospects. Obtain explicit approval for those actions.
